Titanic Data Preparation Project

Project Overview

This project focuses on preparing and cleaning the Titanic dataset using Python and Pandas.

Dataset Source

Titanic dataset: https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv

Tools Used

- Python
- Pandas
- Google Colab

Data Cleaning Steps

1. Loaded the public Titanic dataset.
2. Checked missing values.
3. Filled missing Age values using the median.
4. Filled missing Embarked values using the mode.
5. Replaced missing Cabin values with "Unknown".
6. Checked duplicate rows and data types.
7. Exported the cleaned dataset as a CSV file.

Assumptions

- Median was used to fill missing Age values.
- The mode was used to fill missing Embarked values.
- Missing Cabin values were labelled as "Unknown".
- Duplicate rows were checked and none were found.

Output

The cleaned dataset is saved as "cleaned_titanic.csv".

Conclusion

This project demonstrates basic data cleaning and preparation using Python and Pandas.
